# Demo corpus

Generated by `madrigal-demo-corpus` / `python -m madrigal.demo.corpus.generate`.

- `main.pcap` — primary research capture
- `action_log.json` — scripted client actions aligned to the same run
- `extra.pcap` — second capture with different parameters
- `defects/gap.pcap` — sequence gap → UNKNOWN spans
- `defects/retransmit.pcap` — identical retransmit dedupe
- `defects/overlap.pcap` — overlapping conflict → AMBIGUOUS

Interpretations live under `interpretations/`. Golden apply/validate summaries
are under `golden/`. Stress PCAPs (`stress_*.pcap`) are generated locally and
gitignored.
